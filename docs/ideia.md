# Ideia

O pacote nasceu do tema e dos componentes do Mylo. Loremy e Mylo copiavam componentes um do outro e foram se afastando, e o Salalas tinha visual próprio. Com um pacote só, uma melhoria feita uma vez chega a todos os apps.

## O que não é

Não é uma biblioteca genérica com opções para todo caso. É o jeito do Bruno de fazer interface, com poucas escolhas.

## O que cada app escolhe

A cor principal e os pesos de fonte são de cada projeto: a cor sobrescrita no CSS do próprio app, e o peso escrito onde a tela pede. Superfícies, textos, espaçamentos e animações são comuns, e é isso que faz os apps parecerem da mesma família.

## Adoção

Mylo, Loremy e Salalas já usam o pacote, e cada um passa para a versão nova quando dá. Os ajustes, limpezas e extrações continuam acontecendo aqui, conforme os problemas aparecem no uso, e chegam aos apps a cada nova versão.
