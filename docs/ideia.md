# Ideia

O pacote nasceu do tema e dos componentes do Mylo. Loremy e Mylo copiavam componentes um do outro e foram se afastando, e o Salalas tinha visual próprio. Com um pacote só, uma melhoria feita uma vez chega a todos os apps.

## O que não é

Não é uma biblioteca genérica com opções para todo caso. É o jeito do Bruno de fazer interface, com poucas escolhas.

## O que cada app escolhe

A cor principal é de cada projeto, sobrescrita no CSS do próprio app. Superfícies, textos, espaçamentos e animações são comuns, e é isso que faz os apps parecerem da mesma família.

## Adoção

Os apps só passam a usar o pacote quando ele estiver pronto, e pronto não significa igual ao Mylo. Até lá, ajustes, limpezas e extrações acontecem aqui. Depois, a adoção é feita devagar, um projeto por vez.
